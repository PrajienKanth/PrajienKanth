🧭 Career Compass

<div align="center"><!-- Replace the image URL with your actual project screenshot --><img src="YOUR_CAREER_COMPASS_SCREENSHOT_URL" width="90%" alt="Career Compass"></div>What is it?

Career Compass is an AI-based career guidance platform developed as my final-year team project.

The idea was to help users explore career options based on their interests and skills instead of giving everyone the same recommendations.

What it includes

- 🧭 Career recommendations
- 🧠 Content-Based Filtering
- 🤖 AI career advisor
- 📚 Course and learning-path guidance
- 💻 Coding practice
- 📝 Aptitude tests

Gemini API is used as the AI advisor for questions related to careers, courses and learning paths.

My Contribution

I worked mainly on the frontend and machine learning integration, connecting the recommendation side of the project with the user-facing application.

Built With

"Python" "Machine Learning" "Content-Based Filtering" "Gemini API" "HTML" "CSS" "JavaScript"
